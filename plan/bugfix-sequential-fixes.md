# 本次任务：顺序修复已确认的缺陷

## 已确认问题

1. 宝箱 `permission: ""` 时，方块交互会绕过默认开箱权限。
2. 语言文件提示了 `/crate claim`，但命令未注册，离线奖励没有正式领取入口。
3. 待领取奖励只保存奖励 ID，配置变更后可能丢失奖励。
4. `/crate open` 与方块交互开箱逻辑分叉，保底与替代奖励行为不一致。
5. `plugin.yml` 权限节点与帮助信息不完整，存在误导。

## 修复顺序

1. 修复默认开箱权限回退逻辑。
2. 增加 `/crate claim` 命令，并补齐权限、帮助和提示。
3. 改造待领取奖励持久化，避免配置变化导致奖励丢失。
4. 抽取并统一开箱逻辑，命令和交互共用同一套流程。
5. 补齐 `plugin.yml` 权限定义，修正帮助信息与实际入口一致。

## 备注

- 本次任务为缺陷修复，不新增虚假配置。
- 保持现有多语言结构，新增消息时同步更新语言文件。
