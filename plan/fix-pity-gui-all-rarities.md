## 任务

修复保底 GUI 中稀有度设置与 `config.yml` 不一致的问题，确保保底设置界面可以覆盖 `config.yml -> rarities` 中的全部稀有度。

## 已定位的问题

### 1. 保底界面说明和引导只展示了 3 条

- 文件：`src/main/java/gg/fotia/crates/gui/GuiManager.java`
- 现状：保底 GUI 的说明区域只展示了最多 3 条保底档位/稀有度顺序。
- 影响：当配置里定义了超过 3 个稀有度时，管理员会误以为界面只支持 3 个稀有度。

### 2. 保底 GUI 需要明确支持按配置中的全部稀有度进行设置

- 文件：`src/main/java/gg/fotia/crates/listener/GuiListener.java`
- 现状：右键切换逻辑已使用 `ConfigManager#getNextRarity()`，但当前界面没有把“全部稀有度可配置”呈现清楚。
- 目标：让保底设置界面中保底档位的设置与 `config.yml` 的全部稀有度保持一致，不再产生“只能 3 个”的界面限制感。

## 本次修复范围

- 调整保底 GUI 的说明区域，展示 `config.yml` 中全部稀有度，而不是只截取前 3 个。
- 保留右键循环切换全部稀有度的逻辑，并让界面文案与之保持一致。
- 不新增新的配置项。

## 预期结果

- 在 GUI 进行保底设置时，管理员可以明确看到并设置 `config.yml` 中定义的全部稀有度。
- 保底界面不再表现出“只支持三个稀有度”的限制。
